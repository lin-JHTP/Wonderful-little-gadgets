# 🖥 磁盘空间分配工具

> 将 D 盘（或任意磁盘）的空间划拨给 C 盘（或任意目标磁盘）的 Windows 图形化工具。

---

## ✨ 功能特性

| 功能 | 描述 |
|------|------|
| 🔍 查看磁盘信息 | 调用 `diskpart list volume` 显示当前所有分区信息 |
| ✂️ 压缩源磁盘 | 从指定盘符收缩指定大小（GB），释放为未分配空间 |
| 📈 扩展目标磁盘 | 将未分配空间分配给指定目标盘符 |
| 🚀 一键操作 | 同时完成「压缩 + 扩展」两步操作，带确认弹窗 |
| 🪵 操作日志 | 实时显示 `diskpart` 的完整输出日志 |

---

## 📋 系统要求

- **操作系统**：Windows 10 / 11（64 位推荐）
- **Python**：3.9 及以上（仅使用标准库，无需额外安装包）
- **权限**：必须以 **管理员身份** 运行

---

## 🚀 快速开始

### 方式一：双击 BAT 启动（推荐）

双击 `run_as_admin.bat`，会自动弹出 UAC 管理员权限请求，确认后启动图形界面。

### 方式二：直接运行 Python

右键 `disk_transfer.py` → **以管理员身份运行**，或在管理员命令提示符中执行：

```bash
python disk_transfer.py
```

---

## 📖 使用步骤

1. **启动程序**（管理员权限）
2. 点击「查看磁盘信息」确认当前分区状态
3. 在「源磁盘」区域选择要被压缩的盘符（如 `D`），填写压缩大小（GB）
4. 在「目标磁盘」区域选择要扩展的盘符（如 `C`），填写扩展大小（0 = 使用全部释放空间）
5. 点击「一键：压缩 + 扩展」
6. 确认弹窗后等待操作完成，查看日志输出

---

## ⚠️ 重要注意事项

> **操作前务必阅读！**

1. **操作不可逆**：磁盘分区操作完成后无法自动撤销，请提前备份重要数据。
2. **相邻分区限制**：`diskpart extend` 要求目标分区的**右侧**紧邻未分配空间。
   - 典型场景：收缩 D 盘后，未分配空间在 D 盘右侧，**不能**直接扩展左侧的 C 盘。
   - **解决方案**：使用第三方工具（如 [DiskGenius 免费版](https://www.diskgenius.cn/)）将分区移动后再扩展，或直接用 DiskGenius 完成整个操作。
3. **仅支持 NTFS**：FAT32 或 exFAT 分区无法使用 `diskpart extend`。
4. **系统盘保护**：扩展 C 盘前请确认未开启 BitLocker 或系统快照。

## 🔧 工作原理

```
用户输入（GUI）
  │
  ▼
生成 diskpart 临时脚本（.txt）
  │
  ▼
diskpart /s script.txt
  ├── select volume X
  ├── shrink desired=<MB>   ← 收缩源分区
  ├── select volume Y
  └── extend [size=<MB>]    ← 扩展目标分区
  │
  ▼
输出日志实时显示到 GUI
```
